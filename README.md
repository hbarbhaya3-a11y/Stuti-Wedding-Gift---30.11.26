# Forever — The Wedding Issue

A 14-page flip-through wedding magazine, built as a single web page. Each spread uses a different style:

| Pages | Style | Content |
|---|---|---|
| 1 | Fashion-magazine cover | Masthead, names, date, cover lines |
| 2–3 | Vintage newspaper | "The Forever Chronicle": how you met, the proposal |
| 4–5 | Pink coquette scrapbook | Our playlist and little moments (polaroids) |
| 6–7 | Editorial | Search-page joke and "Who's that guy?" |
| 8–9 | Red and black romance | Hindi lyric headlines and a film strip |
| 10–11 | Minimal beige | Our journey timeline and Happy Wedding |
| 12–13 | Letter and photo booth | A love letter and photo-dump strips |
| 14 | Back cover | "You're my home" music-player card |

## How to edit

**Names and date:** open `s-2LkujtLw9VCy5qex/index.html`, scroll to the `CONFIG` block near the bottom and change `you`, `partner`, `day`, `month` and `year`.

**Photos:** put your images in the `s-2LkujtLw9VCy5qex/photos/` folder using the file names written on each placeholder, for example `photos/cover.jpg` or `photos/moment-1.jpg`. They show up automatically. If a file is missing, its placeholder stays.

**Text:** every placeholder in `[brackets]` is plain text in `index.html`. Search for it and replace it.

## Viewing

- Phone: one page at a time. Swipe or tap the arrows.
- Laptop: two-page spreads. Use the arrow keys or the buttons.
